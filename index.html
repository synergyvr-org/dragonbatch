How to use it

      
    
        
  1. Put the downloaded file in your Skyrim VR Data folder (the one with all the plugins). The console also finds batch files next to SkyrimVR.exe, but Data keeps the game's root folder clean.
          
    
            Using Mod Organizer 2? Keep it out of the game folder entirely.
            
    In MO2's left pane, right-click → All Mods → Create empty mod, name it something like Dragonbatch batch files, then right-click the new mod → Open in Explorer and drop the .txt in at the top level. Enable the mod and launch the game through MO2 as usual: its virtual file system merges the mod into Data, so bat finds the file without anything touching your actual install. MO2 may flag the mod as containing no valid game data — that's fine, plain text files just aren't on its checklist.
    
          
    
        
    2. 
        
  2. Start a new game. Finish character creation, and if your mod list configures itself on first launch (MCM recorders and the like), let it finish first.
    3. 
        
  3. Save. There is no undo for what comes next.
    4. 
        
  4. Open the console and run bat startquests (or whatever you named the file).
    5. 
        
  5. Give it a moment to churn through the stages, then get on with your new life.
    6. 
      

      
Advancing quests by console replays each quest's stages in order, which is the most reliable method there is, but it's still a shortcut through content the game expects you to play. Expect the occasional oddity in NPC chatter and world state, and keep a save from before you ran it.
